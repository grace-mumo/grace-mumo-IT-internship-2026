# Change Request Form

**Change Request ID:** CR-2026-0623-001  
**Date:** 23 June 2026  
**Subject:** Mandatory Endpoint Security Agent Software Upgrade

## 1. Requestor Information

**Requestor:** IT Officer  
**Department:** ICT Department

## 2. Type of Change

**Change Type:** Normal Change

## 3. Change Description

The ICT Department proposes to deploy a mandatory software upgrade to the Agency's Endpoint Security Agent (Antivirus/Endpoint Detection and Response - EDR) across all staff computers.

The upgrade will be implemented on approximately 150 laptops and desktop computers over the weekend to minimize disruption to normal business operations.

### Implementation Schedule

- **Start Date:** Saturday, 27 June 2026
- **Completion Date:** Sunday, 28 June 2026

## 4. Business Justification

The software upgrade is necessary to:

- Improve protection against malware, ransomware, and other cyber threats.
- Address known software vulnerabilities.
- Enhance endpoint detection and response capabilities.
- Maintain compliance with the Agency's ICT security policies.
- Ensure all endpoint devices are running the latest supported security software.

## 5. Risk Assessment

### Potential Risks

- Temporary interruption of endpoint protection during installation.
- Possible software compatibility issues on a small number of devices.
- Failed installation on some endpoints.
- Users who leave their computers switched off may not receive the update immediately.

### Risk Level

**Medium**

### Risk Mitigation Measures

- Test the upgrade on selected computers before full deployment.
- Verify system backups before implementation.
- ICT staff will monitor the deployment throughout the maintenance window.
- Vendor support will be available if required.

## 6. Implementation Plan

1. Notify all staff of the scheduled maintenance.
2. Verify deployment package integrity.
3. Test the upgrade on selected devices.
4. Deploy the software upgrade to all staff computers.
5. Confirm successful installation on all endpoints.
6. Perform post-deployment monitoring and verification.
7. Resolve any issues identified after deployment.

## 7. Rollback Plan

If critical issues arise during implementation, the ICT Department will:

- Stop further deployment immediately.
- Uninstall the upgraded security agent from affected devices.
- Reinstall the previous stable version.
- Restore previous security configurations.
- Test affected computers to confirm normal operation before returning them to users.

## 8. Communication Plan

### Before Implementation

- Notify all staff via email one week before deployment.
- Send a reminder one day before the scheduled maintenance.

### During Implementation

- Provide progress updates to the Principal IT Officer.
- Record any incidents encountered during deployment.

### After Implementation

- Inform all staff that the upgrade has been completed.
- Request users to report any issues to the ICT Department.
